Ferry Run Explorer

Every run of the simulator is a function of its decisions: which fiber runs next, which timer fires, what a call returns. Change one decision, replay the rest, and you get a branch. Each branch here was run, checked against Ferry's contract, and checked by TLC against the TLA+ model.

    A branch is its parent's decisions up to one, that one changed, and fresh choices after it. Each branch is checked against Ferry's contract and, by TLC, against the model.
